Fonts used by this site

Fraunces
  Variable font, weight 400 to 700, optical size 9 to 144.
  Copyright (c) The Fraunces Project Authors (https://github.com/undercasetype/Fraunces).
  Files: fraunces-latin.woff2, fraunces-latin-ext.woff2
  Used for display headings and Scripture passages.

Instrument Sans
  Variable font, weight 400 to 700.
  Copyright (c) The Instrument Sans Project Authors
  (https://github.com/Instrument/instrument-sans).
  Files: instrument-latin.woff2, instrument-latin-ext.woff2
  Used for body text and interface labels.

Both families are licensed under the SIL Open Font License, Version 1.1, which permits
use, study, modification and redistribution, including bundling with a website such as
this one. The full licence text is available at https://openfontlicense.org

OUTSTANDING: the OFL asks that the licence text travel with the fonts. Add OFL.txt to
this folder from the upstream font repositories linked above. The network policy on the
machine that generated these files could not reach the licence source.

These are the latin and latin-ext subsets only, taken from the Google Fonts builds, and
are self-hosted deliberately: the pages then load no third-party resources, render fast
on a weak connection, and keep working offline.
